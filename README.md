# Stop the Churn

Stopping the churn requires a combination of

* *understanding customer behavior and identifying churn factors*, and
* *implementing effective retention strategies*,

In this repository, a machine learning approach is used to address both aspects. 

* **Supervised classification ([`clf`](clf/)):** deploys various classification supervised learning algorithms to predict churn with an ensemble approach, along with exploration of feature importance and factor analysis. 
* **Tabular Q-learning ([`rl`](rl/)):** deploys multiple RL agents in two separate environment definitions to learn optimal retention strategies.
